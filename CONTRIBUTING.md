# Участие в разработке

Спасибо за интерес к Gradient Lab!

## Баги и идеи

Заводите issue: <https://github.com/hwnd1982/gradient-lab/issues>. Для бага —
шаги воспроизведения, ожидание и факт; для фичи — сценарий использования.

## Pull requests

1. Форкните репозиторий и создайте ветку от `main`.
2. `npm ci` — установка зависимостей.
3. Внесите изменения. Стиль кода — prettier (конфиг `.prettierrc` в корне;
   `npm run format` форматирует `src/`).
4. Перед PR локально должны быть зелёными:
   `npx tsc -b --force && npm run lint && npm test && npm run build`.
5. Если меняли прод-функции (`server/`, `shared/`) — прогоните `npm test` и
   пересоберите бандлы: `npm run build` и закоммитьте перегенерированный `api/`
   (бандлы коммитятся сознательно — Vercel деплоит функции из `api/`).
