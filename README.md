## Что это

Gradient Lab — интерактивная лаборатория одного блока: на стейдже живёт настраиваемый блок, поверх его базы (цвет, градиент или картинка) собираются градиентные слои, маски, backdrop-blur ограниченной области с собственной маской и подложкой затемнения. Всё интерактивно: правки в редакторе мгновенно меняют превью, готовый CSS и indented Sass копируются одной кнопкой.

Вторая половина инструмента — точная подгонка по макету (pixel-perfect): загружаете два кадра одного момента — базу без эффекта и референс с эффектом — и лаба считает попиксельный diff (метрики matchPercent / zoneMatchPercent, классификация остатков, вердикт), предлагает стопы по ступеням референса и ведёт цикл подгонки по методике фаз F0–F6; коридор радиуса blur можно прогнать авто-перебором (sweep) одной командой.

Третья — агентский API: ИИ-агент обычным curl читает и пишет состояние блока, а открытая вкладка браузера обновляется live. Полный цикл подгонки (старт → борт-контроль → анализ → правки → сдача Sass) может вести агент, человек контролирует результат глазами. На проде доступны мульти-сессии: несколько агентов и людей работают в изолированных досках, не перетирая стейт друг друга.

## Возможности

### Редактор блока

- База блока: цвет, градиент или картинка (fit/позиционирование) — например, fade в цвет страницы
- Градиенты linear/radial: позиции стопов могут выходить за 0..100 (приём «области затекания»), repeating, radial с явными радиусами (`ellipse Rx% Ry% at Cx% Cy%`)
- Слои поверх базы с rect-областью в % от блока — как слои в Figma: rect таскается и масштабируется хэндлами прямо на канвасе, значения не зажаты в 0..100; у каждого слоя своя opacity и blend-режим
- Маска на весь блок (градиентная, с анимацией from → to в превью)
- backdrop-blur — один псевдоэлемент ограниченной области (rect), несущий вместе градиентную заливку, `backdrop-filter: blur()` и маску растворения — не раскладывается на разные элементы, как в реальном CSS
- Подложка затемнения (underlay) под blur-элементом — конструкция «::before затемнение + ::after blur» со своей rect и заливкой
- Градиентный текст (`background-clip: text`) со своим градиентом
- Undo-история до 50 шагов

### Подгонка по макету

- Материал — два кадра одного момента с одинаковым кропом: base (блок без эффекта) и ref (блок с эффектом из макета)
- Режимы сравнения: opacity / difference / split (A/B-разделитель) / heat-карта попиксельных расхождений; пипетка
- Дифф-анализ с честной эмуляцией backdrop-filter (canvas-блюр внутри rect, clamp-to-edge за краем блока при `stage.isolated`)
- Метрики: matchPercent по всему блоку и zoneMatchPercent по зоне эффекта — честная цифра качества фейда, а не средняя по больнице
- Профиль вдоль оси таргета (ось / колонки / лучи), ступени референса, suggestedStops — автоподбор стопов + кнопка «Применить предложенные стопы»
- Классификация остатков (edge / level / blur), verdict-сводка «что двигать» и hint — готовый следующий шаг по методике
- Борт-контроль старта (warnings): аспекты кадров, трансформ референса, зона blur не накрывает переходы, дубли стопов, нулевой радиус — с готовыми fix-ами
- Sweep — авто-перебор коридора радиуса одной командой с таблицей zoneMatchPercent по значениям
- Журнал итераций подбора (для агента — `GET /api/journal`)

### Сессии и совместная работа

- Мульти-сессии на проде: каждая вкладка — свой слот стейта на сервере («мой агент — моё окно»), без своей сессии — общая доска `default`
- Селектор сессий в хедере: создать, открыть чужую из списка живых
- Join-ссылки `?join=<id>` — коллега или агент открывает вашу доску в своей вкладке
- Кнопка «Инструкция агенту» — копирует бриф (адрес + сессия + минимальный цикл) для запуска агента

### Экспорт и обмен

- Готовый CSS и indented Sass (4 пробела) с вендор-префиксами (`-webkit-mask`, `-webkit-backdrop-filter`), rect — отдельными декларациями
- Анти-бэндинг: детерминированный дизеринг не-ключевых стопов в экспорте
- Пересчёт величин кропа лаборатории в величины макета: px / rem / % дизайн-ширины
- Пресеты: встроенные приёмы из реальных прод-проектов + свои (localStorage в dev, сервер на проде)
- Share-ссылки: весь стейт упаковывается в base64url в hash URL

### Стейдж и навигация

- Фон стейджа: checker / solid / скриншот страницы — честная проверка backdrop-blur и blend-режимов поверх реального контента, с изоляцией backdrop-root
- Зум/пан канвы: Ctrl+колесо — зум к курсору (10..800%), пан — drag пустого места / Space / СКМ, кнопки Fit/50/100/200/300; вид view-only — не влияет на координаты анализа

## Гайд пользователя

Полный цикл «макет → готовый CSS» с агентом занимает минут десять; руками можно то же самое, только дольше. Пошагово:

1. **Откройте лабу.** Локально — `npm run dev` → <http://localhost:5180>, или публичный деплой на Vercel (см. [Deploy](#deploy-на-vercel)). В dev-режиме лаба однопользовательская (одна доска `default`); мульти-сессии — на проде.

2. **Создайте свою сессию** (прод). Кнопка **«Сессия: default»** в хедере → **«+ Создать сессию»** — id сгенерируется сам. Принцип «мой агент — моё окно»: ваш агент будет работать в слоте этой вкладки и не перетрёт чужие доски; `default` — общая доска для всех без своей сессии.

3. **Подготовьте два кадра.** Из макета (Figma-нода или видео/скриншоты) возьмите ровно один момент анимации и выкропите ОБА кадра одним прямоугольником:
    - **base** — блок без эффекта (чистый экспорт);
    - **ref** — блок с эффектом (как должно стать).
      Все посторонние затемнения/градиенты запеките в обоих кадрах одинаково — тогда diff покажет чистый эффект. Запомните масштаб экспорта (пиксели лабы = физпиксели макета; при 2x-экспорте укажите `export.scale = 2`).

4. **Загрузите кадры в лабу.** Секция «Сравнение»: ref-картинка (или загрузите кадры агентом — он положит их в стейт сам). Размер блока = точный аспект кропа. Загляните в warnings (секция анализа) — аспект/трансформ должны быть зелёными до старта подбора.

5. **Запустите агента.** В поповере сессии — **«Инструкция агенту» → «Копировать»**: бриф содержит адрес лабы, id сессии и минимальный цикл. Вставьте его агенту (Claude Code, Cursor и т.п.) вместе с кадрами; полный мастер-промт с методикой фаз — [PROMPT.md](./PROMPT.md). Если предпочитаете ручной режим — дальше крутите редактор сами по тем же метрикам.

6. **Следите за прогрессом.** Каждая правка агента прилетает live:
    - тост **«Агент обновил: …»** над канвой — что именно изменилось;
    - панель анализа: matchPercent / zoneMatchPercent (главная цифра), residuals с классификацией, verdict и hint следующего шага;
    - warnings — если агент забыл починить старт, вы увидите это раньше него;
    - зум/пан и все поля редактора доступны параллельно — агентские PUT не перетирают ваш вид, ваши правки = обычный last-writer-wins.

7. **Финал — экспорт.** Когда зона совпадения вышла на плато (агент отчитается, форма маски утверждается вашими глазами): панель кода → копируйте CSS или indented Sass; панель «Пересчёт в макет» переведёт величины кропа в px/rem/% дизайн-ширины. Готовый блок вставляется в проект как есть: один элемент + псевдоэлементы с масками.

Подсказки по ручным инструментам:

- **Хэндлы rect** (слой/blur/underlay): drag внутри контура — перенос, углы — ресайз (Shift — пропорционально); активный таргет главнее блока — блок в этот момент двигается через Alt+drag или поля X/Y инспектора.
- **Undo** — Ctrl+Z (до 50 шагов); зум/пан — см. [возможности](#стейдж-и-навигация).
- **Пресеты** — ящик в боковой панели: встроенные приёмы как отправная точка, свои сохраняются локально/на сервере.
- **Share-ссылка** — вся доска (без картинок) в hash URL, можно отправить коллеге.

## Гайд агента

Агент работает с лабой тем же циклом, что и человек, только через HTTP:
`GET /api/schema` → `PUT /api/state` (браузер обновляется live) → `GET /api/warnings` (борт-контроль старта) → `GET /api/analysis?target=<таргет>` (метрики, residuals, verdict, hint) → правка стейта → повтор. Полный мастер-промт подгонки blur-затухания — [PROMPT.md](./PROMPT.md) (скопировать агенту целиком, приложив два кадра или Figma-ноду), контракт всех эндпоинтов с curl-примерами — [API.md](./API.md); исполняемая методика фаз F0–F6 — `GET /api/methodology`.

## Сессии и совместная работа

Каждая вкладка браузера на проде живёт в своей **сессии** (слот стейта на сервере) — агенты и люди не перетирают доски друг друга. Селектор в хедере: «+ Создать сессию», клик по живой сессии из списка — открыть чужую, «Копировать ссылку (?join=)» — ссылка вида `…/?join=<id>`, открыв её, коллега или агент попадает в эту сессию. Без своей сессии все работают в общей доске `default`. Пресеты — общая библиотека; журнал и анализ — на сессию. Детали — [API.md](./API.md), раздел «Сессии».

## Быстрый старт

Node.js 24+.

```bash
git clone https://github.com/hwnd1982/gradient-lab.git
cd gradient-lab
npm install
npm run dev      # http://localhost:5180 (+ dev Agent API, см. API.md)
```

> Примечание: в репозитории лежит `.npmrc` с `registry=https://registry.npmmirror.com/`
> (реестр машины автора). Если вам удобнее дефолтный npmjs — удалите эту строку
> из `.npmrc` после клонирования, на работу проекта это не влияет.

Прочие команды: `npm run build` (статика в `dist/` + бандлы функций в `api/`), `npm run lint`, `npm test`.

## Deploy на Vercel

`npm run build` собирает статику в `dist/` и самодостаточные бандлы функций в `api/` — Vercel подхватывает их автоматически (framework Vite, стор — Upstash Redis, бесплатного тарифа хватает). Пошаговый чеклист — [API.md](./API.md#прод-vercel), раздел «Setup». На любой другой static-хостинг собирается без API — приложение полностью работает и локально.

## Архитектура

- `src/schema.ts` — zod-схемы состояний, из них выводятся все типы (`src/types.ts`)
- `src/store.ts` — zustand-стор: стейт блока, undo-история, UI-флаги (compare, anim, dev-API)
- `src/cssgen.ts` — генерация CSS/Sass для копирования и стилей превью
- `src/targets.ts` — адресация градиентов (слой / маска / blur-маска / clipText / anim)
- `src/components/` — Stage, Inspector, GradientEditor, CompareSection, AnimSection, PresetDrawer, CodePanel
- `src/presets/` — встроенные приёмы из реальных проектов и localStorage-хранилище пользовательских
- `src/lib/` — color, drag, autofit, imageCache, shareUrl (base64url в hash), agentTransport (клиент Agent API: dev-middleware / прод-поллинг)
- `vite-plugins/agent-api.ts` — dev Agent API (Vite-middleware + SSE)
- `server/`, `shared/` — прод Agent API для Vercel (функции + Upstash REST-клиент + общие хелперы); `api/` — генерируемые самодостаточные бандлы из `server/functions` (сборка `scripts/build-functions.mjs`); источников в `api/` нет
- `presets/` — файловые пресеты dev-сервера (пишутся UI и агентом)
